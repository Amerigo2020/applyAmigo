# Changelog

## 0.1.0

Initial preview release.

* Persistent workspaces with profile, evidence, job pipeline, drafts and sprint blocks.
* Four ATS adapters adapted from OpenJobs and keyword coverage adapted from career-ops.
* Responsive dashboard, opportunity discovery, application tracking and draft review.
* Optional model provider, explicit AI permission and approval invalidation when facts change.
* JSON workspace export and text draft export.

This release prepares applications and tracks their progress. It does not submit applications or send messages.
