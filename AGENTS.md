# applyAmigo

Open source application workspace combining OpenJobs discovery and career-ops matching.

Keep changes in the isolated development worktree. Preserve all upstream license and copyright notices. Do not include personal application data, CVs, provider keys, or authentication credentials in source control.

Applications are drafts until the person explicitly approves them. There is no automated application or email submission transport. Marking an application as sent records an action the user performed outside the app.

Use only facts in the saved profile when drafting. Missing evidence stays visible. Do not generate application text when a user marks AI usage as prohibited. Match scores express documented heuristic fit, never an acceptance probability.

Run type checking, meaningful domain/API checks, a production build and desktop/mobile browser checks before release. Capture the starter baseline and final screenshots. Keep German product copy concise and avoid dash punctuation as a sentence connector.
